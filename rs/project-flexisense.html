FlexiSense:

一种通过服装改造实现无电池手势识别的工具包

A Toolkit for Battery-Free Gesture Recognition via Garment Modification

UIST25 Poster

Abstract

We present FlexiSense, a democratized toolkit designed to retrofit everyday clothing into battery-free interfaces for gesture recognition. Users can develop smart textiles by connecting and strategically placing relevant modules on garments, guided by detailed instructions. The system is self-powered by electromagnetic induction, harvesting kinetic energy from user movements. Gesture sensing relies on stretchable conductive fabrics, where resistance changes directly correspond to user actions. With low-power, multimodal outputs for closed-loop interaction, this toolkit democratizes the creation of self-powered interactive apparel, opening new avenues in wearable computing and human-computer interaction.

我们提出了 FlexiSense，一款旨在将日常服饰转化为无需电池的手势识别界面的普及工具包。 用户可以根据详细说明，将相关模块连接并巧妙地放置在衣物上，轻松打造智能纺织品。 该系统通过电磁感应实现自供电，从用户的运动中收集动能。手势识别依赖于可伸缩的导电织物， 其电阻变化与用户动作直接相关。具备低功耗、多模态输出的特性，支持闭环交互， 这款工具包让自供电互动服饰的创造变得更加普及，为可穿戴计算和人机交互开辟了新的可能性。

Mechanism

能量收集: 基于法拉第电磁感应定律,通过在手镯中集成磁铁和线圈，将手腕的运动转化为稳定的 5V 电源输出。

动作识别: 通过测量导电织物由于运动产生的电阻变化，检测身体运动，特别是在关节处的动作。

Modular Components

1. 发电模块

通过佩戴在手腕上的旋转线圈与磁体阵列，从自然的手腕运动中采集动能并转化为电能；

2. 信号处理模块

包含导电织物与腕部设备，后者用于稳定发电模块输出的电能， 处理织物电阻变化产生的传感信号，并控制输出模块；

3. 输出模块

提供三种低功耗反馈模块，分别用于产生视觉、听觉和触觉反馈；

4. 连接模块

通过导电线和按扣式连接件实现简单且可靠的电气连接方式。

Workflow

发电模块组装

将用于发电的手镯连接到信号模块的电源输入端口。

导电织物固定

剪下一块导电织物，用导电丝线将其缝制到衣物的指定区域，并将两端连接到信号模块的信号输入端口。

输出模块连接

根据所需的反馈方式，选择视觉、触觉或听觉模块，并将其连接到腕带的输出引脚。
